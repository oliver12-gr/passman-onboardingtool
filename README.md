# Introducing PassMan, Version 0.1.0!

The password manager onboarding tool. This little tool is a simple way to start using a password manager, beginning with your most important accounts.

Share this with your friends and family to encourage them to uplift their password game!

## The app has 2 modes:

### Standard Mode
<img width="477" height="482" alt="image" src="https://github.com/user-attachments/assets/8c1f00de-e016-4f22-8cf6-8bda4bb5b115" />

Create a Bitwarden account or connect an existing one and any entered account information will be added as credentials to your Bitwarden account. (Uses Bitwarden CLI)

### Manual Mode
<img width="477" height="474" alt="image" src="https://github.com/user-attachments/assets/251da452-e180-484c-8470-c4e8dbe48ad1" />

Manual mode takes you through the same account selection process and then provides a CSV/JSON that you can import manually into your password manager of choice.

The app is designed to be used once and it's dependencies are self-uninstalling.
